# Ficha de registro

Se llena una ficha por cada vez que se hace una prueba, aunque salga mal. Se copia esta plantilla con el nombre `registro_N_fecha.md`, por ejemplo `registro_2_2026-12-05.md`, y se guarda junto a las fotos de esa jornada. Si una prueba falla, la ficha dice cómo falló, porque esa también es la prueba.

## La prueba

| Campo | Qué se anota |
|---|---|
| Prueba y variante | Por ejemplo, «2, variante B» |
| Fecha, hora de inicio y de término | |
| Lugar | Dónde se hizo; en la prueba 1, también la altura sobre el mar y el tipo de suelo |
| Técnica, fuente y página | Como en el archivo de la prueba |
| Pasaje de la novela | Con su página |
| Escala | Tamaño natural, 1:5 o 1:10 |

## Los materiales

| Campo | Qué se anota |
|---|---|
| Piedra | De dónde salió, de qué clase es y cuánto pesó |
| Tierra | De dónde salió y cómo es. Si es posible, una prueba de cinta: cuánto se estira un rollo húmedo antes de quebrarse |
| Paja | Qué paja, de dónde, si se le cortaron las raíces |
| Agua | Cuánta se usó |
| Proporciones | Piedra y tierra, paja y barro, en peso o en volumen, y cuál de las dos |
| Herramientas | |

## El trabajo

| Campo | Qué se anota |
|---|---|
| Manos | Cuántas personas, quiénes y qué hizo cada una |
| Tiempo | Cuánto llevó cada paso |
| Cómo se apisonó o se pisó | Con qué, cuántas veces y en capas de qué espesor |
| Secado | Cuántos días y con qué tiempo |
| Lo ritual | Si quienes participaron hicieron algo que no pidió la prueba, se anota con su permiso, sin fotografiarlo |

## Lo que pasó

| Campo | Qué se anota |
|---|---|
| Medidas | Las de la sección «Qué se mide» de la prueba |
| Pesos | En húmedo y en seco |
| Fisuras y fallas | Dónde, cuándo, de qué forma |
| Lo que no se esperaba | |
| Qué se retuvo y qué se descartó al cambiar de escala | La pregunta de Chandler (2017: 214) |
| Qué cambiaría la próxima vez | |

## Las fotos

- **Fondo neutro y luz lateral,** para que se lean la textura y el relieve.
- **Una escala visible** en cada foto: una regla o una tarjeta con centímetros.
- **El mismo punto de vista** para las fotos de una serie, como las del derrumbe de la prueba 2 o las de la mancha de sol de la prueba 5.
- **Sin retoques.** Se puede recortar y enderezar; no se borra ni se agrega nada.
- **Los nombres de los archivos** dicen la prueba, la variante, la fecha y el número: `p2_B_2026-12-05_014.jpg`.

Las fotos de personas solo se publican con su permiso.
